# BlockStudioLegend

BlockStudioLegend is a distributed, multi-threaded framework for real-time data processing and analytics, leveraging auto-scaling capabilities.

BlockStudioLegend is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/BlockStudioLegend.git`
2. `cd BlockStudioLegend`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
